## §1 环境决策

- pymoo 0.6.2 直接 pip 装好（无需 N3 的清华 wheel 手法）；scipy 1.18 多起点 SLSQP 做单目标参考端点。
- 问题矩阵定型：ZDT1–3（解析校准）+ pymoo 内置 WeldedBeam（带官方参考前沿 257 点）+ 自研 PressureVessel/SpeedReducer + pymoo 内置 Clutch（制动器族，整数索引）。
- 文献数字离线不可核 → 参考口径两类：解析/官方参考前沿（权威）+ 自算单目标端点（自研问题）。自算端点恰好落在经典解区域（PV 5885.34、SR 2994.46 且 g8/g11 活跃），作为公式正确性的自证，报告如实标注。

## §2 建模与公式自证

- 减速器边界最初与 g10/g11 不相容（l1≤8.3 但 1.5·d1+1.9≥9.4 → 全空间不可行，SLSQP 60 起点全灭）。按经典解区域反推自洽边界（d1∈[2.9,3.9]、双跨距 [7.3,8.3]、d2∈[5.0,5.5]）后 SLSQP 立即命中 (3.5, 0.7, 17, 7.3, 7.7153, 3.3502, 5.2867) f=2994.46，g8/g11 精确活跃——单测钉住这两个活跃约束。
- 压力容器连续成本最优 5885.3352 @ (0.7782, 0.3846, 40.32, 200)——与经典 benchmark 连续解同区域。
- Clutch 质量公式手算对照（π(ro²−ri²)·t·(Z+1)·ρ）单测 rel 1e-9。

## §3 调试链（坑）

1. **pymoo 0.6 evaluate 返回 tuple**：`res["F"]` 崩 → `F, G = problem.evaluate(...)`。
2. **pymoo Clutch 库 bug**：n_ieq_constr=19 vs 实际 8 列 G → 子类改 8（clutch_wrap.py）。
3. **Clutch 索引编码**：测试传物理值 800 越界（数组长 401）→ 传索引 200。
4. **PV g3 量级 1e6**：活跃约束残差 1.33 被 1e-6 判据误杀 → 约束全量级归一化。
5. **非支配过滤方向写反**（keep[dom]=False 删的是支配者）：ZDT 近全非支配侥幸不暴露、WB GD 0.14→0.05 修正后减半、PV 前沿从被污染点恢复。单测 test_nondominated_front 钉方向。
6. **F1-only 罚函数双目标结构性失效**：实测可行率 1.7%——不可行但 f2 更优的点罚多大都不被支配。加 B2（罚全部目标）对照，可行率 53%。结论进报告 §5 负结果。
7. **修复策略复核口径**：群体存未修复 X → 评价可行率须先 repair 再查原约束。
8. **eliminate_duplicates 收缩种群**：形状断言改区间。
9. **TOPSIS 对称平局**（三点贴近度全 0.5）→ 测试用非对称中点；HV 手算容斥（0.46 非 0.96）。
10. solve_single 全起点失败时需要手选可行 x0 兜底（随机起点大多不可行）。

## §11 v1.2 调试战记（pymoo 随机泄漏排查全程）

1. **pymoo evaluate 单值返回**：`return_values_of=["F"]` 单项直接返数组，`r[0]` 取成第一行 → isinstance 防御（11/12 脚本均踩）。
2. **res.X=None 挤 (1,1)**：小预算无可行最优时 `np.asarray(None, dtype=float)` 造出 (1,1) 数组，n_var=7 断言炸出 "Input dimension 1 are not equal to n_var 7" 误导信息 → run_moea 兜底取末代种群 CV 最小者再重评。
3. **跨调用随机状态泄漏（最深一坑，排查 ~1 天）**：E21 参考方向扫描两次运行 p=6 档 IGD 7.98e-2 vs 7.26e-2 漂移，仅 seed=1 变、2/3 稳。排查链：① 钩 `np.random.default_rng` 统计熵回落（seed=None→OS 熵）：3 run 出现 494 次、9 run 2830 次；② 排除 ref_dirs 就地改写（array_equal 未变）；③ 排除共享对象污染（全新问题/方向实例也翻）；④ 排除 legacy `np.random`（全局指纹不变）与全局种子（`np.random.seed(0)` 无效）；⑤ 形态分析：同 seed 连跑 6 次也翻、插入别的 seed 反而不翻——真随机特征而非状态污染；⑥ `traceback.format_stack` 抓熵回落调用栈铁证：`tournament.py:70 func_comp → nsga3.py:36 compare(...) → util default_random_state 装饰器 → np.random.default_rng(None)`。修复：`comp_by_cv_then_random_fixed` 显式透传 random_state（缺省 `default_rng(0)` 兜底禁熵）+ make_moea 注入 `TournamentSelection`；--fix 对照（熵回落换 default_rng(0)）三连全同证实机制。NSGA-II 的 `binary_tournament` 本就传 random_state（nsga2 从头确定）、MOEA/D 无 compare 路径。回归单测 `TestCrossCallDeterminism` 3 项。
4. **alg.selection 不存在**：pymoo GeneticAlgorithm 把 selection 包进 Mating 对象 → 断言路径是 `alg.mating.selection`。
5. **13_summary % 格式化冲突**：字符串里的 `±1%` 撞上 `%d` 模板（`%公` 被当非法格式符，ValueError）→ 改 f-string。
6. **E20/E21 重跑落盘**：修复改变 nsga3 随机消耗流 → 用修复后代码重跑 10/11（495.6s / 164.4s），JSON 与最终代码一致；E22 只用 run_nsga2/pooled_front 不受影响免重跑。
