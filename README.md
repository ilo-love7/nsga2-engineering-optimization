# N9 · NSGA-II 工程多目标优化

博远线上科研新项目提案 v2 · N9（机械设计/优化 · ★★）。

pymoo 0.6.2 实现 NSGA-II，求解焊接梁/压力容器/减速器/离合器（制动器）四类约束工程双目标问题，复现 Pareto 前沿并做 GD/IGD/HV 收敛评估、约束处理策略对比与 TOPSIS 折中选点。基准文献：Deb et al., IEEE Trans. Evol. Comput. 2002。

## 流水线

```
pymoo Problem 建模（2 内置 + 2 自研）─→ 01 单目标端点校验（多起点 SLSQP）
        │
        ├─→ 02 NSGA-II 前沿复现（ZDT 解析 / WB 官方参考 / 自算端点对照）
        ├─→ 03 调参扫描 pop×gen → GD/IGD/HV 收敛曲线
        ├─→ 04 约束策略：可行性规则 / 罚(f1) / 罚(全) / 死刑 / 修复
        ├─→ 05 TOPSIS 折中选点 + 汇总
        ├─→ 06 双向 ε-约束真参考前沿（PV / SR 整数枚举 z / WB 官方交叉验证）  [v1.1]
        ├─→ 07 memetic 精修（ASF + 端点 SLSQP）vs raw 前沿                  [v1.1]
        ├─→ 08 IGD-代数收敛曲线（10 种子）+ 等预算 pop/gen 对比             [v1.1]
        ├─→ 09 TOPSIS 权重轨迹 + 膝点 + 扰动稳定率                          [v1.1]
        ├─→ 10 多算法等预算对比（NSGA-II/III/MOEA-D，NFE=20000）           [v1.2]
        ├─→ 11 三目标减速器（参考方向密度 + TOPSIS-3D + 第三目标价值）      [v1.2]
        ├─→ 12 鲁棒优化（公差扫描 + 可靠度-代价 + mean/worst）             [v1.2]
        ├─→ 13 v1.2 汇总表                                                 [v1.2]
        ├─→ 14 约束处理七配置对比（rules/death/罚/动态/自适应/ε + 标度对照） [v1.3]
        ├─→ 15 ELECTRE III / PROMETHEE II vs TOPSIS 选点稳定性             [v1.3]
        ├─→ 16 PV 离散整数 NSGA-II（三管线 + 网格分辨率扫描）               [v1.3]
        └─→ 17 v1.3 汇总表                                                 [v1.3]
```

## 关键口径

- 文献数字离线不可核 → 参考前沿两类：解析/官方（ZDT、pymoo welded_beam.pf）+ 自算单目标端点（SLSQP 60 起点，报告如实标注）。
- 约束输出按量级归一化（g3 ~1.3e6 不归一化会误判不可行）。
- 非支配过滤方向单测钉住（方向反了会删优留劣）。
- MOEA/D 原生不支持约束 → DeathPenaltyWrapper 转无约束（口径差异报告 §17 披露）；res.F/G 一律回原问题重评。
- pymoo 0.6.2 NSGA-III 锦标赛熵回落 bug 已修复（`comp_by_cv_then_random_fixed`，同 seed 跨调用可复现，报告 §21 坑 18）。
- 罚/死刑/ε 的指标一律回原问题重评（罚值、1e12、松弛 G 不进指标）；可行判据 G≤1e-6（约束已按量级归一化）。
- ELECTRE 排序用净可信度流（非完整 III 蒸馏，如实标注）；稳定性必须双口径（index 稳定率 + 跳变中位，报告 §14/§25）。
- 离散管线的指标在 quantize 后的设计点上计算（eval_repair 的原始 X 会被投影回网格）。
